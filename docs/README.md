# Documentation

- `architecture/` specifies the packet pipeline, the wire protocol, the
  trace format with its canonical run-digest contract, and the two-host
  failover and multicast gap-fill design.
- `benchmarks/methodology.md` defines the measurement, evidence, and
  provenance rules every published result must satisfy.
- `overview.md` is the standing project description.
- `security/stride-order-entry.md` is the STRIDE threat model of the
  order-entry path, with the mitigations it prioritises.
