# Benchmark results

Benchmark evidence, grouped as `<version>/<environment>/`. No results are
published yet: measurements collected before the release tag lack a
verifiable source revision and are deliberately not retained. Published
evidence is collected from the tagged release revision with
`scripts/replay/run-evidence.sh`; the required provenance fields, warm-up
policy, and retention rules are defined in
[the benchmark methodology](../docs/benchmarks/methodology.md).
