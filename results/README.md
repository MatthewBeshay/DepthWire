# Benchmark results

Benchmark evidence, grouped as `<version>/<environment>/`. The v1.0.0
bundle is [`1.0.0/fedora44-dpdk24/`](1.0.0/fedora44-dpdk24/): a
nine-point replay rate sweep, reproduced conformance digests, and three
overload-recovery runs, collected from the tagged release revision by
`scripts/replay/run-evidence.sh`. The required provenance fields, warm-up
policy, and retention rules are defined in
[the benchmark methodology](../docs/benchmarks/methodology.md).
Measurements taken before the release tag lacked a verifiable source
revision and were deliberately not retained.
